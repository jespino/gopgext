# fuzzystrmatch, in Go

A port of PostgreSQL's
[`contrib/fuzzystrmatch`](https://www.postgresql.org/docs/current/fuzzystrmatch.html)
(version 1.2) to Go, as a drop-in replacement: the same SQL functions with
the same results and errors.

| Go source            | Ported from (PostgreSQL 19)                                     |
|----------------------|-----------------------------------------------------------------|
| `main.go`            | `fuzzystrmatch.c` (soundex, difference, metaphone) and `src/backend/utils/adt/levenshtein.c` |
| `dmetaphone.go`      | `dmetaphone.c` (Double Metaphone)                               |
| `daitch_mokotoff.go` | `daitch_mokotoff.c`                                             |
| `dm_table.go`        | the coding chart generated by `daitch_mokotoff_header.pl`       |
| `csrc/upper.c`       | calls PostgreSQL's `str_toupper()`, so `dmetaphone` upper-cases like the original |

```sh
gopgext install -version 1.2 -trusted contrib/fuzzystrmatch
```

## Verification

**Upstream regression tests**: PostgreSQL's own `pg_regress`, with the
`sql/` and `expected/` files of `contrib/fuzzystrmatch` unmodified, passes
against this port:

```sh
$(pg_config --pkglibdir)/pgxs/src/test/regress/pg_regress --temp-instance=/tmp/fsm \
    --bindir=$(pg_config --bindir) --inputdir=<postgresql source>/contrib/fuzzystrmatch \
    --encoding=UTF8 --no-locale fuzzystrmatch fuzzystrmatch_utf8
# ok 1 - fuzzystrmatch
# ok 2 - fuzzystrmatch_utf8
```

**Differential test**: `differential.sql` compares all 11 functions with
the original C library on a generated corpus (random strings over a
Unicode alphabet, and name-like strings made of the letter groups the
phonetic rules look for), with random costs and bounds for levenshtein. On
100,000 strings, in a `C` and a `C.UTF-8` (builtin provider) database: 0
mismatches. Errors (length limits, overflow, invalid output lengths) have
the same SQLSTATE and message.

Speed, on 300,000 rows (PostgreSQL 19): levenshtein 0.81 s (C: 0.61 s),
dmetaphone 0.33 s (C: 0.36 s), daitch_mokotoff 1.41 s (C: 1.16 s), soundex
0.25 s (C: 0.19 s).
